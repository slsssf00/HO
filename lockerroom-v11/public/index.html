⚙️ 실제 경기 데이터 연결 / JSON 불러오기

JSON 형식: {"matches":[{"id":"match-1","league":"프리미어리그","home":"리버풀","away":"아스널","kickoff":"2026-11-14T17:00:00+00:00","result":"H"}]}
result는 H(홈 승), D(무), A(원정 승), 미정이면 null. 점수 계산은 결과가 입력된 경기만 반영해.
