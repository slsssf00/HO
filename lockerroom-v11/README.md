# THE LOCKER ROOM 10.0 — 실시간 서버 시제품

## 실행
Node.js 20 이상 설치 후 이 폴더에서:

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000` 열기. 다른 기기와 함께 접속하려면 HTTPS를 지원하는 Node.js 호스팅에 배포하고 해당 URL을 공유해야 합니다.

## 기능
- Socket.IO 실시간 채팅, 접속자 수, 공용/팀별/풋살 채널 분리
- 닉네임·구단 기반 프로필 동기화
- WebRTC 음성 P2P 신호 교환 및 마이크/스피커 ON/OFF
- 기존 9.0 3D 라커룸 및 로컬 미니게임 화면 유지

## 한계 및 운영 주의
- 현재 3D 아바타 위치 동기화, 예측 랭킹 DB, 풋살 일정 DB는 **아직 서버에 연결되지 않았습니다**.
- 팀 회의실 접근 제한은 UI 수준이며, 서버는 선택 구단을 자기 신고 방식으로 받습니다. 실제 비공개 구단 방은 계정/구단 인증 필요.
- 마이크는 HTTPS/localhost에서만 허용. 일부 네트워크는 별도 TURN 서버가 필요하며 P2P 방식은 소규모 방에 적합합니다.
- 서버 재시작 시 접속자 정보는 초기화됩니다. 채팅은 영구 저장하지 않습니다.
- 공개 운영 전 인증, 관리자/신고, 욕설 필터, 요청 제한, 보안 점검, 영속 DB 및 확장 가능한 음성 SFU 도입이 필요합니다.

## V11 동물 마스코트
- 3개 리그 구단 선택에 따라 창작 동물 머리 모델과 팀 유니폼 색상이 변경됩니다.
- 캐릭터 스타일과 리본/모자/안경을 선택할 수 있으며 액세서리는 브라우저에 저장됩니다.
- 공식 구단 마스코트나 공식 로고가 아닌 자체 제작 해석입니다.
- 온라인 다른 사용자의 3D 캐릭터 렌더링은 아직 구현되지 않았습니다.
